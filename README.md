# AI创作小程序源码，文生图，图生图，可对接任何图像AI模型

源码获取：ym7k.com/19846/

随着 AI 绘图需求持续增长，很多团队想要搭建自己的 AI 绘画平台，而不是依赖第三方 SaaS 平台的额度与接口限制。这套 AI 创作小程序源码，以小程序 + H5 作为前端入口，内置文生图、图生图核心能力，设计了通用模型对接层，**不绑定单一绘图模型**，可以灵活接入 Stable Diffusion、Midjourney 代理、Flux、DALL・E、通义万相、文心一格等各类图像生成模型，是一套轻量化、可扩展的 AI 绘图业务底座。

## 技术架构

主流采用 FastAdmin + ThinkPHP 后端，UniApp 开发微信小程序 + H5，一套代码多端发布。
后端作为调度中台，负责用户管理、参数接收、请求转发、任务队列、结果缓存、计费、权限控制；前端小程序负责输入提示词、上传参考图、设置绘图参数、展示历史作品、保存下载图片。
核心设计亮点是**模型适配器层**，把前端的绘图参数统一封装成标准请求，再通过适配器转换成不同 AI 图像模型需要的接口格式。新增模型只需要新增适配器，不用大规模改动前端业务逻辑。源码私有化交付，支持二次开发。

## 核心业务模块拆解

### 1. 文生图（Text to Image）

用户输入正向提示词、反向提示词，选择风格、尺寸、生成数量、采样器、步数、CFG 权重等参数，提交生成任务。
支持预设风格模板：写实、二次元、国风、插画、3D、logo、海报等，降低普通用户写提示词门槛。任务异步排队处理，避免超时，生成完成后推送通知。

### 2. 图生图（Image to Image）

上传参考图，配合提示词进行重绘。支持重绘幅度（denoising 强度）调节，可实现图片扩图、风格迁移、图片修复、局部重绘。很多场景如老照片翻新、图片改风格、草图转效果图都依赖这个能力。部分版本附带蒙版局部重绘功能。

### 3. 通用模型对接适配器（核心亮点）

区别于市面上很多硬编码绑定某一个模型的 AI 绘画源码，这套系统做了解耦设计：

- 统一入参：提示词、尺寸、步数、图生图参考图、重绘强度、种子；
- 适配器转换：把统一参数翻译成各个模型的 API 协议；
- 支持本地部署模型（SD、Flux）、云端 API 模型（各大厂商图像接口）混合接入；
- 可以设置模型分组，用户前端自由切换模型，后台配置不同模型的计费单价。

服务商可以根据客户预算选择方案：预算低接入国内厂商 API 按量调用；有 GPU 服务器则对接本地 SD/Flux 私有化模型，降低长期调用成本。

### 4. 用户作品、历史记录、收藏下载

每一次生成自动保存作品记录，用户可以在个人中心查看历史绘图任务、原图、参数、提示词，支持收藏、重新生成、复用参数、下载图片。支持作品广场，开启公开展示，其他用户可以查看、点赞、参考提示词。后台可配置是否开启广场，也可设置私密模式。

### 5. 计费、会员、变现体系

内置多种商业化方案：

- 算力点数 / 积分：每次绘图消耗点数，不同模型消耗点数不同；
- VIP 会员：会员每日免费次数、部分模型免点数、优先排队；
- 充值套餐：充值购买点数；
- 分销推广：邀请好友充值，推广人获得奖励；
- 单独付费：高清图、更快加速队列单独计费。

后台支持配置不同模型的点数消耗规则，方便区分低成本模型和高消耗大模型。

### 6. 任务队列、限流与风控

绘图是耗时任务，系统采用异步队列处理，防止接口超时、并发崩溃。支持并发上限、用户频率限制，防止恶意刷接口。
内置敏感词审核，提示词、图片结果可对接内容安全审核接口；后台可查看所有生成记录、原图、提示词，支持违规作品下架、封禁账号。

### 7. 后台管理与数据统计

后台可管理模型配置、适配器参数、风格模板、用户、订单、充值记录、作品审核。数据看板统计生成量、各模型调用量、充值营收、用户活跃度，支持导出报表。

## 适用场景与边界

✅ 适用场景：

- 个人 / 工作室 AI 绘画小程序、海报设计工具；
- 服务商给企业客户搭建私有 AI 绘图平台；
- 教育、自媒体、电商设计内部素材生成工具；
- 多模型聚合平台，同时提供多种绘图模型给用户选择。
